# 实验性功能

这些功能存在于仓库中，但不是当前项目叙事的中心。

## 次要界面

- 监控
- GitHub 摘要与指标
- 用户与 Token 用量视图
- 提示词库 UI
- 代码洞察
- 对话

## 为什么它们是次要的

项目的核心主张是：

- 触手
- 待办事项
- Claude Code 终端
- 子代理编排
- 代理间消息传递

除非文档另有说明，其余一切都应视为辅助或实验性内容。

## 文档规则

不要让这些功能主导落地页或核心概念页面。
